# Car Object Detection & Segmentation

A comparative study of three deep-learning pipelines for detecting cars in road / traffic images:

1. **YOLOv8** — modern single-stage detector (Ultralytics).
2. **Faster R-CNN** — two-stage detector with a Region Proposal Network.
3. **R-CNN (VGG16 + Selective Search)** — classic two-stage pipeline implemented from scratch in Keras/TensorFlow.

The notebooks in this repository contain the **exact runs reported in the thesis / project report**. Outputs (metrics, predicted boxes, plots) are preserved inside the notebooks so reviewers can see results without re-executing them.

> **Note:** Re-running the notebooks may produce slightly different numbers due to non-deterministic GPU ops and random initialisation. The committed outputs are the canonical results referenced in the report.

---

## Dataset

The project uses the **Car Object Detection** dataset (Kaggle):

- Source: <https://www.kaggle.com/datasets/sshikamaru/car-object-detection>
- 1001 training images, 175 testing images
- Bounding-box annotations in `train_solution_bounding_boxes.csv`

Images that exist on disk but have no bounding-box row in the original CSV are treated as **negative (no-car)** samples. The augmented file `updated_annotations.csv` is generated by an early cell of the R-CNN notebook.

## Environment

Developed and tested with:

- Python 3.10+
- TensorFlow / Keras (R-CNN, Faster R-CNN notebooks)
- Ultralytics YOLOv8 (YOLO notebook)
- OpenCV, scikit-learn, selectivesearch
- Jupyter / JupyterLab

Install dependencies:

```bash
pip install -r requirements.txt
```

GPU is recommended (CUDA-enabled TensorFlow / PyTorch build) but not required to *view* the notebooks.

---

## Reproducing the Results

The notebooks are intended to be opened and read top-to-bottom. If you wish to re-run them:

1. Download the dataset and place it as described in *Dataset*.
2. Launch Jupyter:
   ```bash
   jupyter lab
   ```
3. Run each notebook **from the project root** — all paths (`data/training_images`, `data/train_solution_bounding_boxes.csv`, …) are relative to it.

## Results

The three pipelines are implemented in dedicated notebooks. Each notebook reports its own quantitative metrics (mAP, precision, recall, training time) and qualitative prediction visualisations.

| Model | Backbone | Approach |
|:--|:--|:--|
| YOLOv8 | CSPDarknet (Ultralytics) | Single-stage detector |
| Faster R-CNN | ResNet-50 + FPN | Two-stage detector with Region Proposal Network |
| R-CNN | VGG16 (ImageNet) | Selective Search proposals with classifier and bounding-box regressor |

A full side-by-side comparison and discussion is provided in the accompanying thesis report.
